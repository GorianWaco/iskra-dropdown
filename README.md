# Iskra drop-down

Rozszerzenie GNOME Shell. Skrót zjeżdża okno Iskry z góry panelu, drugi skrót gasi model i zwalnia pamięć karty.

Uuid: `iskra-dropdown@gorian`. Działa z powłoką 45–50.

## Instalacja

```bash
git clone https://github.com/GorianWaco/iskra-dropdown.git ~/Projekty/iskra-dropdown
~/Projekty/iskra-dropdown/install.sh
```

Potem wyloguj się i zaloguj, żeby powłoka zobaczyła nowy katalog. Sam program Iskra jest osobno: skrót w `~/.local/bin/iskra`.
